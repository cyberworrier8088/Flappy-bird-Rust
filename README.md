# Flappy-bird-Rust
A flappy bird game in rust, using bevy game engine. highly optimized for performance, and smooth gameplay

## Features
- Smooth gameplay
- Optimized for performance
- Using bevy game engine
- Cross-platform support
- Easy to play
- Small and safe
- purely made in rust.


## Installation
To install and run the game, follow these steps:

1. Make sure you have Rust installed on your system. If not, you can install it from [rustup.rs](https://rustup.rs/).

2. Clone this repository:
   ```bash
   git clone https://github.com/cyberworrier8088/Flappy-bird-Rust.git
   cd flappy-bird-rust
   ```

3. Run the game:
   ```bash
   cargo run
   ```
